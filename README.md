moodle-mod_clickableboxes
======================
Clickable Boxes resource

With this resource you can add boxes to your course page. 
Each box can contain an image and a description.
If you add also a link to the box, users can click on it to follow the link.
You can add and manage several boxes in a single resource.

## [Changelog](CHANGES.md)

## Install

1. Copy the plugin directory "clickableboxes" into moodle/mod/. 
2. Check admin notifications to install.
3. Done
